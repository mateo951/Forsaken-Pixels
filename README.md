# 👑 Forsaken Pixels

*A survival city-builder where your kingdom is not the land you hold — it's the people who follow you.*

---

## About the Project

Forsaken Pixels is a pixel-art survival city-builder prototype focused on migration mechanics and strategic relocation.

Built in Unity, this project is an ongoing refactor of an early prototype, evolving into a cleaner architecture with modular systems, ScriptableObjects, and event-driven design patterns.

This repository reflects my process of revisiting old code, rebuilding systems, and shaping better development practices.
